# 项目需求文档

## 项目概述

- **项目名称**: AI 德州扑克对决  
- **项目目标**:  
  - 开发一个系统，模拟多个大模型（Large Language Models, LLMs）之间的德州扑克比赛。  
  - 提供一个美观的前端界面，展示比赛过程，便于后续用于制作视频。  
  - 通过项目熟悉 Flutter 框架，提升开发技能。  
- **项目背景**:  
  - 德州扑克是一种策略性游戏，结合概率、决策和心理学。  
  - 通过大模型参与比赛，探索 AI 在复杂决策中的表现。  
- **项目范围**:  
  - 开发一个支持多人大模型参与的德州扑克游戏环境。  
  - 实现大模型与游戏环境的交互机制。  
  - 使用 Flutter 开发美观的前端界面。  

## 功能需求

### 游戏环境

- **德州扑克规则**:  
  - 遵循标准的无限制德州扑克（No-Limit Texas Hold'em）规则。  
  - 包括发牌、下注（弃牌、跟注、加注）、摊牌和胜负判定。  
- **选手数量**:  
  - 支持 3-6 个大模型同时参与比赛。  
- **赛制**:  
  - 采用现金游戏（Cash Game）模式。  
  - 每位选手起始筹码固定，例如 1000 筹码。  
  - 设置固定盲注，例如小盲 1 筹码、大盲 2 筹码。  
  - 比赛进行固定手数，例如 100 手。  
- **游戏流程**:  
  - 自动完成发牌、轮流下注和胜负判定。  
  - 每手牌结束后更新选手筹码并记录比赛数据。  

### 大模型整合

- **API 调用**:  
  - 为每个大模型提供当前游戏状态，包括手牌、公共牌、底池大小和下注额等信息。  
  - 接收大模型返回的决策，例如"弃牌（fold）"、"跟注（call）"或"加注至 X（raise to X）"。  
- **提示设计**:  
  - 设计简洁明确的提示（prompt），确保大模型理解游戏状态和可选行动。  
  - 示例提示："你的手牌是 A♠ K♠，公共牌是 Q♠ J♠ 10♣，底池有 50 筹码，当前下注额为 20。你要做什么？（fold, call, raise to X）"  

### 前端界面

- **界面设计**:  
  - 开发一个美观的游戏界面，确保视觉效果适合视频展示：  
    - 虚拟扑克桌，背景优雅且不过于分散注意力。  
    - 每个大模型显示独特的头像和名称。  
    - 实时展示手牌、公共牌、底池和下注信息。  
    - 选手筹码和比赛进度以直观的方式呈现（例如数字或进度条）。  
- **动画效果**:  
  - 实现发牌、下注等动作的流畅动画。  
  - 高亮当前行动的选手，突出关键决策时刻。  
- **用户体验**:  
  - 界面布局清晰，信息层次分明。  
  - 使用吸引人的配色方案和现代设计风格。  

## 非功能需求

- **性能**:  
  - 游戏环境响应迅速，确保比赛流畅。  
  - 大模型 API 调用延迟可控，避免影响游戏节奏。  
  - 前端渲染高效，避免卡顿或延迟。  
- **可靠性**:  
  - 游戏逻辑稳定，无重大错误。  
  - 大模型决策有效，避免异常输出。  
- **美观性**:  
  - 前端界面设计精美，视觉效果专业且吸引人。  
  - 确保界面元素在不同设备（移动端、桌面端）上的适配性。  

## 技术栈

- **前端**: Flutter（Dart 语言）  
- **后端**: Node.js（JavaScript）  
- **大模型 API**: 根据所选模型调用对应 API（如 OpenAI API、Anthropic API 等）  
- **数据库**: 可选，用于存储比赛数据（如 MongoDB 或 PostgreSQL）
